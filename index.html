BasePulse

Onchain data for AI agents, on Base.

A pay-per-call API that serves live Base chain data to AI agents over the x402 protocol — $0.001 USDC per request, no API keys, no subscriptions.

Endpoints

  • GET /gas — current Base gas price
  • GET /block — latest block number + timestamp
  • GET /balance/:address — ETH balance of any address

Built with x402 + Base Builder Codes · source on GitHub
